How to read this

FUB conversion is closed people ÷ leads received for the selected received-date cohort. Command Center closed production uses the same date fields as a close-date range. These measures are not additive.

Use Original receiving agent for lead-assignment decisions. Command Center production uses the transaction's recorded agent and source because historical transactions currently lack FUB person IDs.

Appointment metrics include FUB appointments that carry a person link. Every breakdown column can be filtered; number filters accept values such as >=10, <5, or =3. Click any column title to sort.
